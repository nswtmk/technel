## 0. 今年度（mU 2026）からの変更点の要約

| 項目 | mU 2026 | mU 2027（案） |
|---|---|---|
| オンライン科目 | 8科目（各16h、8回×2h） | **4科目（各10〜12h、5〜6回×2h）** |
| 構成の軸 | 4ステップを12科目で分担 | **4ステップ＝4科目に一対一対応** |
| フィールド講義 | 科目ごとに別日程（9月・10月・11月・3月） | **9〜10月に集約。1泊が基本、連泊も可** |
| 実践・ゼミ | なし（科目課題＋最終課題） | **1〜3月「つくるを問い直す実践」ゼミ（5ゼミ×最大20人）を新設** |
| 修了要件 | 必須2科目＋選択3科目＋課題 | **4科目＋フィールド＋ゼミ（要確認）** |
| オプション | Techキャンプ（西表島）など | Techキャンプ、建築Unlearn（VUILD）、農業、原初技術実践の月額会員など、**Technel主催の別講義として並走** |

ねらい：科目数を絞って「全員が同じ4ステップを通る」設計にし、最後にゼミで自分のテーマに落とす。今年度は科目ごとの申込に大きな偏りがあり（後述）、受講生が全体像をつかみにくかった。

## 3. フィールド講義（9〜10月・北杜の森）

- 基本：1泊2日。シルバーウィーク全日、9〜10月の週末を多く開放し、場合によっては平日も使う。
- 受講生が増えた分だけ開催日を増やす（枠が埋まったら次の週末を開ける）。
- 連泊：希望者は追加費用で最大6日間連続参加できる。
- 講師：相馬皓介（原初技術）を軸に、これまでフィールドで教えてきた講師が凝縮して集まる（南部隆一・比嘉夏子、原島大輔、長谷川愛、平野朗 ほか ※要確認）。
- 今年度の実績：原初技術実践（10/10-13）は感想平均4.60、沓名さんは11月の「森で考える」にも参加希望。自然共生のデザイン実践（9/12-13）も満足度5.0（n=1）。
- 森の設備（意識研の資料より）：2027年冬に瞑想用テラス・採水システム・風呂を設置予定。ホールはVUILDと建築予定。**9〜10月時点で何が使えるかを確認して、受け入れ人数の上限を決める。**
- 論点：フィールド講義を修了要件に入れるか（入れると地方・海外の受講生が修了できない）。入れる場合は代替（Techキャンプ等）を認めるか。

## 4. ゼミ「つくるを問い直す実践」（1〜3月・新設）

### 設計
- 5ゼミ、各最大20人（定員計100人）。
- 各ゼミ 合計約10時間：**合同ゼミ（2h）→ 分科ゼミ 3回（各2h）→ 合同ゼミ（2h）**。オンライン。
- 最終合同ゼミの前に、各自がプレゼン動画またはプレゼン資料をアップし、全員が相互に見る。最終合同ゼミはそれを前提に進める。
- 最終課題は幅を持たせる：高度な作品・プロジェクトを作りたい人はそれを出す。忙しい人は「この講義で自分が何を問い直し、今後どうしたいか」の振り返りでよい。各自の状況に応じて選べる。

### ゼミ担当（案）
| ゼミ | 担当 | 想定テーマ（仮） |
|---|---|---|
| 1 | 七沢智樹 | 技術の根源と「つくる」の問い直し |
| 2 | 長谷川愛 | スペキュラティブ・未来を見る |
| 3 | 増田さん ※要確認 | （未定） |
| 4 | 杉山歩 | 地域・社会実装 |
| 5 | 客員・特任の講師から1〜2名 ※要確認 | （未定） |

- 林篤志をゼミ担当に入れるかは要確認（STEP4担当のため、社会実装ゼミとして持つのが自然）。
- 受講生のゼミ選択：STEP4の最終回でテーマを宣言 → 希望を取り、定員超過は事務局で調整。

### 今年度の感想からの示唆
- 「講義を事前動画にして事前に質問を集め、当日は議論中心に」（周さん・7/6）。ゼミはまさにこの形。オンライン科目でも一部の回で試す価値がある。
- 「情報量が多いときこそブレイクアウトルームで吐き出したい」「Zoomのコメントログを見たい」。ゼミでは少人数の対話を確保する。
- 「初回で様子見をして他の科目に変える」要望 → 4科目全員共通の設計なら科目変更の問題はなくなる。

## 6. 受講形態と料金（論点のみ・金額は未定）

今年度：認定コースA（5科目）9万円／B（オンライン8科目）10万円／C（全12科目）19万円／科目履修1.8万円／法人応相談。学割・県民割・U25あり。

来年度の論点：
1. **基本は「4科目＋ゼミ」の一本に絞るか。** 科目履修を残すなら、どの科目を単科で開くか（今年度は未来学だけ単科の申込が多かった）。
2. フィールド講義を基本料金に含めるか、別料金か。連泊の追加費用の単価。
3. ゼミを含むコースの定員（最大100人）に対して、ゼミなしの「視聴のみ」プランを置くか。
4. 法人プラン：ネクセラ（Vimeo版アーカイブサイト）の型を、コンセント・KEIPE・RIDE・山梨県庁に広げる。ゼミを法人単位で1つ持つ（法人ゼミ）案もある。
5. アーカイブ視聴期限（今年度は2027年6月末）と来年度開講（7月）の接続。今年度受講生への継続割引。
